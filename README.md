## 本地開發與運作流程

- **開工流程**：載入本機設定，閱讀最新對應筆記，確認 Git 狀態。
- **收工流程**：確認無敏感資訊（API key/Tokens），更新筆記，確認 Git Diff 後僅提交變更檔案。
